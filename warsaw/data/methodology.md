# Warsaw / How agents build — audit method

Audited 5 October 2026. This case study explains development-time AI engineering. It is not a certification of the current game.

## Scope
Selected Warsaw-related Codex root-session plans, reports, direct tool outputs and browser records were reviewed alongside current code and project artifacts. The main Claude session was found under the broader workspace Claude project archive; targeted episodes are sampled separately. The game-specific Windows Claude archive consists of empty or warmup records. No complete private transcripts are served by this website.

## Evidence rules
Observed means a recorded action or direct output. Documented means inspected implementation, written rule, report, or design. A report of success remains a report unless corroborated. Historical checks apply to their snapshot and conditions. Test implementations do not themselves prove a test run.

## Limits
Selected episodes do not constitute exhaustive session coverage. No comparable sequential baseline, complete cost record, or universal gameplay performance certification is available. Approval guardian transcript copies are not separate engineering agents. A virtual soak simulates network timing; screenshots, browser frame intervals, and GPU work time answer different questions.
